ApplyDomainKitConventions(ModelConfigurationBuilder, ValueConverter?)

套用 DomainKit 的全域模型 convention。若宿主提供 dateTimeOffsetConverter， 則對所有 DateTimeOffset 與 Nullable<T> 屬性套用該轉換器。

public static ModelConfigurationBuilder ApplyDomainKitConventions(this ModelConfigurationBuilder configurationBuilder, ValueConverter? dateTimeOffsetConverter = null)

Parameters

configurationBuilder ModelConfigurationBuilder

模型設定建置器。

dateTimeOffsetConverter ValueConverter

宿主提供的 DateTimeOffset 值轉換器；為 null 時不套用轉換。

Returns

ModelConfigurationBuilder

模型設定建置器。

Remarks

由宿主 DbContext 在覆寫 ConfigureConventions 時呼叫。 DateTimeOffset 的儲存型別因資料庫而異（SQL Server 有原生 datetimeoffset，SQLite 無）， 故 DomainKit 不內建特定 converter，改由宿主依 provider 傳入對應的 ValueConverter（seam）。 EF Core 會對 Nullable<T> 自動套用同一轉換器。
